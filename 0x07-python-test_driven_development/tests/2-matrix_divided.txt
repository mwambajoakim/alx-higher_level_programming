These are tests for a function that divides elements of a matrix by a number
============================================================================
Check that import module is successful:
	 >>> matrix_divided = __import__("2-matrix_divided").matrix_divided

Check that module has a docstring:
	 >>> mod = __import__("2-matrix_divided").__doc__
	 >>> len(mod) > 1
	 True

Check function has a docstring:
	 >>> func = __import__("2-matrix_divided").matrix_divided.__doc__
	 >>> len(func) > 1
	 True

Check matrix elements divided by number:
	 >>> matrix = [[2, 4], [4, 6], [8, 10]]
	 >>> matrix_divided(matrix, 2)
	 [[1.0, 2.0], [2.0, 3.0], [4.0, 5.0]]

Check matrix elements divided by zero:
	 >>> try:
	 ...     matrix_divided(matrix, 0)
	 ... except Exception as e:
	 ...     print(e)
	 ... 
	 division by zero

Check matrix elements division with different row size:
	 >>> matrix = [[2, 3], [9, 7, 7], [8, 0]]
	 >>> try:
	 ...     matrix_divided(matrix, 2)
	 ... except Exception as e:
	 ...     print(e)
	 ... 
	 Each row of the matrix must have the same size

Check each element of matrix is either an integer or float:
	 >>> matrix = [[2, "Jim"], [9, "world"], [8, "hello"]]
	 >>> try:
	 ...     matrix_divided(matrix, 2)
	 ... except Exception as e:
	 ...     print(e)
	 ... 
	 matrix must be a matrix (list of lists) of integers/floats

Check matrix elements divided by a string:
