## Introduction
Just like in C programming Python also has ways of making decisions in the programs. In this project I go through making programs that use loops and if and if...else statements to make decisions.

## 00 - This program will assign a random signed number to the variable number each time it is executed it shows whether the number stored in the variable number is positive or negative.
- The variable `number` stores a different value every time the program is run
- The output of the program is:
	- The `number`, followed by
		- if the number is greater than 0: `is positive`
		- if the number is 0: `is zero`
		- if the number is less than 0: `is negative`
- followed by a new line
